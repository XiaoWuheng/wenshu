文枢帮助独立创作者把资料、摘录、稿件、核验、素材授权和交付放进同一工作区。本项目从 0.5.0 起只交付桌面应用，不再提供网页部署或网页迁移入口。

## 使用

- 安装版：`Wenshu-0.5.0-Setup-x64.exe`，按向导安装。
- 免安装版：完整解压 `Wenshu-0.5.0-win-x64.zip`，打开 `文枢.exe`，保留所有附带文件。
- 用户无需安装 Node.js；资料整理和写作可以离线使用，模型调用按所选服务连接。
- 更新前退出旧版本。安装目录与数据目录相互独立，卸载默认保留数据。

## 指定数据目录

首次进入有上手引导。进入「设置与数据 → 更改数据目录」，选择容量充足磁盘中的**空文件夹**。

应用复制当前工作区、恢复点和加密模型配置，逐文件核对 SHA-256，全部成功后记录新位置并重启。原目录保留；失败不会切换。请不要将新目录放在当前工作区内部。

默认目录为 `%APPDATA%/Wenshu/workspace`，目录偏好在 `%APPDATA%/Wenshu/preferences.json`。安装版与免安装版使用同一 Windows 用户的偏好。指定磁盘离线时，会提示重新选择已有工作区或退出，不会静默新建空工作区。

## 保存和恢复

- 输入停止 600 毫秒后异步请求保存；切换项目、重要操作和关闭窗口前刷新未保存内容。
- 写入临时文件、刷新文件数据后替换正式文件；失败时保留未保存标记，不显示成功。
- 工作区和备份使用同一校验与 **100 MB** 上限。
- 「保存版本 / Ctrl+S」保存**当前稿件**；「版本比较」并排查看、恢复单篇，保留最近 50 个版本。
- 自动稿件版本每分钟最多一个。采用 AI、插入摘录、恢复旧稿前保留版本。
- 删除资料、核验项、素材或稿件进入回收站，可单条恢复。
- 工作区整体恢复是单独入口，最近 60 个恢复点；恢复前再保留当前内容。
- 启动发现损坏时，可恢复最近有效恢复点或选择外部备份；保留损坏原文件。
- 定期导出备份到其他磁盘，设置显示最近外部备份时间。同盘历史不能替代外部备份。

## 资料与核验

在项目中导入或拖入 TXT、MD、CSV、SRT、VTT、DOCX、含文字 PDF。每次最多 10 份，每份 30 MB；PDF 最多 500 页，每份提取文字最多 200 万字符。扫描 PDF 无 OCR，无法解析时提供明确错误。

打开「资料与摘录」，划选原文，填写页码或时间点。PDF 提取文字自带页码标记。摘录可插入稿件并保留来源标记，核验项可关联来源或具体摘录。导入的是提取文字，不会自动归档原始二进制附件；请自行保管原文件。

稿件修改后，关联的已核验陈述退回待核验；旧记录未关联具体稿件时采用保守提醒。系统不会自动认定事实为真。

## AI 协作

选择 OpenAI、DeepSeek、通义千问或其他兼容服务。自定义服务支持 Chat Completions / Responses、手动模型 ID 与无密钥本地服务。

- 默认不发送资料，按次勾选允许使用的摘录。
- 展示目标服务与模型，可展开本次发送全文，合计上限 20,000 字符。
- 支持取消生成；服务商可能已产生部分用量。
- 原文与建议按段落顺序对照，勾选后采用；段落重排需人工审阅。
- 新数字、日期形式和引语提示仅为辅助规则，不能识别所有新增人名或事实。
- 稿件在生成后变化时拒绝覆盖，需重新生成或手动复制。
- 密钥在桌面服务端通过系统能力加密保存；不进入正文备份。

## 交付

在发布检查页选择交付稿、填写公开署名，预览 Markdown 排版，导出 DOCX、PDF 或 HTML。默认只含正文和署名，不附带内部资料、核验记录或密钥。外部图片不自动加载。Word 对基础标题、段落、强调和列表进行转换，复杂表格以文本呈现。

专注写作可隐藏导航与资料栏，Esc 退出。设置可导出不含正文、项目名、路径和密钥的诊断信息。版本检查需要维护者确认的 GitHub 仓库地址，只查询并打开发布页，不自动安装。

## 开发与构建

开发者需要 Node.js 22.12+：

```sh
npm ci
npm start
npm test
npm run build:win
node scripts/smoke-desktop.mjs
```

输出位于 `dist/0.5.0/`。GitHub Actions 仅提供桌面构建；文件白名单不含用户数据、模型配置或 `.env`。

### 数字签名

默认构建未签名。具备有效 Windows 发布者证书后，通过安全环境变量提供 `CSC_LINK`、`CSC_KEY_PASSWORD`，运行：

```sh
npm run build:win:signed
```

签名构建启用强制签名，缺少证书会失败。不要将证书、密码提交仓库。当前环境没有发布者证书，不能宣称已签名。
