# 数据与隐私说明

## 数据存放位置

文枢当前把项目数据保存在运行应用的浏览器 `localStorage` 中。应用不提供用户账号、云端同步、广告、分析或遥测；可选 Node 服务只为同源 AI 请求提供代理，不保存项目数据。清理浏览器数据、卸载浏览器或更换设备前，请在“设置与数据”中导出备份。

浏览器本地存储不提供应用级加密；能够使用该浏览器配置文件的人可能访问这些记录。请谨慎保存未公开稿件、敏感采访材料或个人信息。

## 网络请求

纯静态模式不向 AI 服务发送内容，也不包含第三方 JavaScript 或字体服务请求。启用自托管 Node 服务后，只有每次明确确认的文本会发送到 .env 中配置的模型供应商；API 密钥留在服务端环境，不返回浏览器。供应商对请求内容的处理和保留遵循其各自政策，请先评估其数据条款，不要发送敏感材料。部署在 GitHub Pages 时，静态网页访问仍会与 GitHub Pages 建立连接并受 GitHub 的服务隐私政策约束。

## 备份和导入

导出的项目数据是用户可读取的 JSON 文件。请自行妥善保管。导入会覆盖当前工作区；导入前先备份当前数据。不要把包含敏感稿件或个人信息的备份上传到公开 Issue、Pull Request 或公共仓库。

## 离线缓存

通过 HTTPS 或本地 HTTP 服务器访问时，Service Worker 会缓存应用外壳文件，不会缓存项目内容。清理站点缓存只会移除可离线加载的界面文件，不应代替“设置与数据”中的用户数据管理。

## AI 计划

AI 功能只发送任务指令与文本输入框内容；项目名称、其他稿件、资料库和备份不会自动附带。用户可在发送前检查并编辑文本。结果标记为待审阅；事实提取仅创建待核验条目，不会自动标记事实已核验或素材已获授权。Node 服务不记录请求正文；网络日志和模型供应商的数据留存仍受部署环境及供应商政策约束。
