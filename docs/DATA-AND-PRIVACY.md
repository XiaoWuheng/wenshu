# 文枢桌面版的数据与隐私

项目、稿件版本、回收站、来源摘录以明文保存在用户指定的数据目录。默认位置为 Windows 用户应用目录下的 Wenshu/workspace。安装位置与数据位置独立，卸载默认保留数据。

更改目录会复制并核对文件，原目录保留，复制失败不会切换。旧副本不会自动删除。配置文件记录数据位置。磁盘离线时提示用户重新连接或选择已有工作区。

密钥通过 Electron safeStorage 使用系统能力加密。密钥不在正文备份中，不能通过复制加密文件保证跨系统账户使用。数据目录变更会复制当前加密配置。

AI 仅发送本次输入与勾选摘录。可查看发送全文，默认不附带资料。取消请求不保证服务商不计费。模型结果由用户决定是否采用，核验结论由用户确认。

自动恢复点保留最近60个，稿件版本保留最近50个，均在同一数据目录。回收站和损坏原件仍可能包含已删除内容。清空工作区不等于安全擦除历史、旧目录或外部备份。

资料文件导入提取文字，不会自动把原始二进制文件复制到文枢。交付只包含选定稿件和署名；正文里已有的敏感信息需用户自己审查。

诊断导出使用固定字段白名单：版本、运行平台、架构、工作区是否可读、恢复点数量、生成时间；不包含正文、项目名、文件路径、模型密钥。应用不自动上传诊断或遥测。

更新查询在用户操作后访问其填写的 GitHub 仓库发布API，显示说明并按用户选择打开发布页。不会自动安装程序。
