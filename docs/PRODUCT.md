# 文枢 0.5.0 产品与验收清单

## 定位

面向有资料整理、采访、写作和修订需求的独立创作者，先完成可追溯、可恢复、可交付的单人工作流。只交付桌面版。

## 逐项改造记录

| 提出的问题 | 实现 | 验收情况 |
| --- | --- | --- |
| 无法指定数据路径 | 设置中选择空目录，复制并校验，成功切换，原目录保留；离线目录提示重选 | 复制、范围限制与保留原目录自动检查通过；磁盘拔插需实机验收 |
| 工作区 20 MB、备份 8 MB 不一致 | 统一为 100 MB，复用同一结构校验 | 超过 8 MB 的备份检查通过 |
| 保存版本实际回退整个工作区 | 单篇 50 个版本、并排比较，整体恢复独立入口 | 单稿件恢复且保留其他项目检查通过 |
| 保存失败仍提示成功 | 关键保存检查结果，失败阻止成功提示；关闭前刷新并提醒 | 故障注入检查通过 |
| 损坏后无法进入恢复 | 启动原生提示恢复点或外部备份，保留损坏原件 | 底层损坏恢复检查通过；原生对话流程待实机验收 |
| 每字同步保存影响输入 | 600 毫秒输入合并与异步请求，切换及退出前刷新 | 输入逻辑检查通过；100 MB 长时间性能待测 |
| 桌面与网页文案混用 | 移除网页部署、迁移，桌面指南重写 | 源码与说明已统一 |
| 删除记录难以恢复 | 单条回收站，可恢复资料、素材、核验项和稿件 | 删除/恢复来源检查通过 |
| AI 误改不可撤销 | 采用前保存稿件版本，拒绝覆盖已变化稿件 | 逐段采用检查通过 |
| 同盘历史不等于备份 | 原生外部备份选择，记录最近备份时间 | 文件保存与结构校验已覆盖 |

| 写作时资料难用 | 原文选择、摘录位置、插入稿件、来源标记 | 已接入界面；长篇PDF排版需人工核对 |
| 核验记录和稿件脱节 | 改稿后将相关已核验项退回待核验，可关联具体摘录 | 改稿复查提醒检查通过 |
| AI未利用项目资料 | 逐次选择摘录、完整发送预览、目标模型显示 | 未勾选资料不发送检查通过 |
| AI结果难审阅 | 逐段对照采用、数字/引语提示，保存前版本 | 逐段采用检查通过；提示不承诺完整事实识别 |
| 无法取消、错误难排查 | 取消请求并通知上游断开；分类权限、限额、接口错误 | 模拟模型路由通过；真实供应商需自有Key |
| 首次使用引导不足 | 首次桌面指南及选择目录入口 | 已实现，无网页迁移 |
| 安装/升级/卸载未验证 | 保留数据配置；隔离验收脚本与CI流程 | 打包程序隔离启动通过；CI脚本已提供，未在用户真实安装上执行卸载 |
| 缩放与小屏布局 | 720×520 最小窗口、缩放菜单、窄屏比较列折行、专注模式 | CSS实现；不同DPI与多显示器实机视觉仍待验收 |

| 定位过宽 | 核心流程聚焦资料型独立创作者 | 待真实工作者连续使用验证，不能用代码测试代替 |

## 发布条件

自动检查、打包启动、安装升级卸载、真实模型及多机人工验收分别记录。当前代码改造不等于全部外部验收已完成。没有证书、正式发布仓库或真实账户时应标记明确依赖，不虚构结果。

## 界限

导入保存提取文字，不归档二进制原件。PDF无OCR。比较按段落顺序，不是语义对应算法。提示只辅助发现新增数字和引语，人名与事实仍需人审。单用户工作区，不提供云同步与多人协同。
